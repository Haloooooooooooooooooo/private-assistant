# 个人知识内化助手 电脑端 V1 页面设计稿

日期：2026-05-15
范围：电脑端（不含手机端）

## 1. 设计目标

围绕“收录后处理”构建最小可用闭环：
- 低摩擦收录
- 自动内化与自动整理
- 关键节点轻确认
- 证据化问答与沉淀复用

## 2. 电脑端产品形态

采用混合形态：
1. Web 主工作台：收录箱、知识库、AI 助手
2. 桌面快捷收录窗：全局快捷键唤起，仅做快速收录

说明：全局快捷键弹窗属于桌面端能力，不由纯 Web 单独承担。

## 3. 状态与术语

用户可见主状态：
1. 稍后看
2. 待内化
3. 已沉淀

语义规则：
- 标签与主题分离。
- 标签为轻量标记（可多选、可重命名）。
- 主题为知识结构归属（单条笔记最多归属 1 个子主题）。

## 4. 模块总览

电脑端 V1：
1. 收录箱（主工作页）
2. 知识库（图谱主视图）
3. AI 助手（独立模块）
4. 笔记追问抽屉（从笔记详情触发）
5. 桌面快捷收录窗（系统能力）

## 5. 页面 1：收录箱（主工作页）

### 5.1 顶部与提醒

- 顶部仅保留信息 icon。
- 点击 icon 打开小日历：
  - 有记录/无记录日期使用不同颜色。
  - 点击某天弹出当日信息弹窗（背景模糊）。
  - 若当日同时存在今日提醒与周反馈，则同层展示两张卡。

### 5.2 主体布局、搜索与快速添加

- 主体采用上下结构：
  - 上方：快速添加栏
  - 下方：记录呈现栏
- 搜索框与记录呈现栏在同一块区域（不分离）。
- 搜索为实时下拉联想（Notion 风格）。
- 搜索结果直接显示在主体列表。
- 自动添加已选标签 `搜索结果`；标签右上角 x 可移除，移除后退出搜索结果态。

快速添加栏字段：
- 内容输入（文本/链接/可直接粘贴图片）
- 批注输入（我的理解，选填）
- 状态选择（稍后看/收藏，二元按钮）
- 添加附件
- 添加按钮（支持回车提交）

提交成功后记录即时出现在列表。

交互说明：
- 内容输入区优先承载主输入，支持混合录入：链接、纯文本、截图、文件。
- 内容输入与 `我的理解` 采用左右结构并列展示，减少视线切换成本。
- `我的理解` 是可选项，但在视觉上不应弱到被忽略，因为它会直接影响后续内化质量。
- 附件采用统一入口，不按图片/PDF/文档拆按钮。
- 状态选择改为底部左侧二元按钮：`稍后看/收藏`。
- `添加记录` 固定在底部操作区右侧；点击 `添加记录` 或在主输入区按回车提交后，记录立即进入列表。

### 5.3 筛选与列表动作

筛选结构：
- 一级状态：全部 / 稍后看 / 待内化 / 已沉淀
- 二级筛选：来源、时间、标签
- 标签支持自定义（新增、重命名、删除、多选）

列表统一字段：标题、来源、收录时间、状态、标签、操作。

- 异常标记不单独占列；仅在异常记录标题后显示红色感叹号，悬浮后展示报错原因。

状态动作：
1. 稍后看：查看原笔记、转待内化（主）、一键内化、删除
2. 待内化：查看原笔记、一键内化（主）、删除
3. 已沉淀：查看原笔记、AI笔记（主）、在知识库定位、删除

动作差异：
- 查看原笔记：跳转到原始来源。网页/小红书/B站等直接打开对应来源；纯文本记录打开弹窗展示完整文本。
- AI笔记：在当前上下文就地查看已内化的笔记内容。
- 在知识库定位：跳转知识库并自动定位高亮目标笔记。

### 5.4 详情抽屉与内化流程

- 任意记录都可打开详情抽屉。
- 详情抽屉支持：查看摘要、写批注（我的理解）、编辑标签、改状态。
- 详情抽屉内提供 `查看原笔记` 入口，用于跳转原始来源；纯文本则打开全文弹窗。
- 附件区域支持继续追加上传附件。
- 用户在详情抽屉写下的“我的理解”，会作为 AI 内化依据。

一键内化流程：
1. 点击一键内化
2. 打开内化草稿抽屉
3. 系统生成 7 字段草稿
4. 用户轻确认/微调并保存
5. 记录进入已沉淀，可直接查看或定位到知识库

### 5.5 附件读取规则（V1）

- 支持本地文件上传（选择/拖拽）与剪贴板图片粘贴。
- 前端使用统一附件入口，不按类型拆分按钮。
- 后端按类型自动分流：
  - 图片：OCR 提取文本
  - 文档：按扩展名走对应解析器
- V1 支持：pdf、docx、md、txt、png、jpg、jpeg、webp
- V1 暂不支持（示例）：xls、ppt、zip（保留记录并标记不支持原因）
- 每个附件生成独立记录；附件以 chip 展示并支持移除。

### 5.6 今日提醒与周反馈逻辑（V1）

#### 今日提醒

- 生成频率：每天生成 1 次（默认 22:00，本地时区）。
- 任务条数：固定 3 条（不足 3 条则按实际返回）。
- 候选范围：稍后看、待内化中的未完成记录。
- 优先级建议：
  1. 待内化优先于稍后看
  2. 有批注/有高价值来源的记录优先
  3. 等待时间更久的记录适度前置
- 展示内容：
  - 今日概览：待处理数（稍后看、待内化、已沉淀新增）
  - 今日建议处理：最多 3 条，每条包含“为什么今天处理 + 建议动作”

#### 周反馈

- 生成频率：每周 1 次（默认周一 09:00，本地时区）。
- 统计时间窗：上一个自然周（周一 00:00 至周日 23:59）。
- 最小指标集：
  1. 本周新增记录数
  2. 本周已沉淀数
  3. 关注主题 Top3
  4. 可复用笔记数
  5. 下周建议补强 1 个主题

#### 日历“有记录”判定

- 有记录日期定义：当日存在任一有效行为即记为“有记录”，包括：
  - 新增收录
  - 状态变更（如转待内化、完成内化）
  - AI 助手回写笔记
- 无上述行为则标记为“无记录”。

#### 历史卡片刷新规则

- 今日提醒按日快照保存，默认不自动重算历史日期。
- 周反馈按周快照保存，默认不自动重算历史周。
- 若发生补录或批量修正，允许手动触发“重新计算当日/当周卡片”。

## 6. 页面 2：知识库（图谱主视图）

### 6.1 布局

- 两栏结构：
  1. 主区域：全景知识图谱
  2. 右侧：笔记详情抽屉（可调宽、可关闭）
- 不使用中栏笔记列表。

### 6.2 图谱能力

- 节点类型：主题节点 + 子主题节点 + 笔记节点
- 支持：缩放、拖拽、悬浮高亮关联
- 不同主题使用不同颜色
- 被选中的节点在图谱中保持高亮

### 6.3 主题管理策略

- V1 结构层级固定为两层：主题 -> 子主题（不做子子主题）。
- 不提供手动新建主题/子主题入口。
- 主题结构新增/合并/拆分由 AI 自动处理。
- 用户保留主题/子主题重命名能力。
- 子主题细分通过“标签 + 笔记语义连接”表达。

### 6.4 归属与关联

- 图谱采用双层网络模型：
  - 结构边：主题 -> 子主题 -> 笔记（表达归属）
  - 语义边：笔记 <-> 笔记（表达知识关系）
- 单条笔记仅主归属 1 个子主题。
- 笔记可跨主题与多条笔记直接连线。
- 关系类型：补充、对比、延伸、反例、应用。

### 6.5 内容与衍生

- 已内化笔记支持生成思维导图（基于原文与内化结果）。
- 系统保存原始内容快照，用于追溯与后续问答依据。

## 7. 页面 3：AI 助手（独立模块）

### 7.1 定位

- 仅做知识问答，不做通用闲聊问答。
- 默认保留多轮会话记忆。

### 7.2 回答约束

- 每条回答必须附参考记录（标题、来源、时间）。
- 无充分依据时明确不确定，不做无依据断言。

### 7.3 与笔记联动

- 笔记详情页始终提供 `基于此笔记提问`。
- 点击后打开右侧追问抽屉，自动挂载该笔记上下文。

### 7.4 回写笔记

- 每条助手回答支持 `加入笔记`。
- 回写到固定区块：`小助手对话沉淀`。
- 入库内容包含：原问题、规范化问题（原问题模糊时生成）、助手回答、时间。
- 笔记详情内容均可编辑；对话沉淀支持单条编辑/删除。

## 8. 系统能力：桌面快捷收录窗

- 全局快捷键唤起。
- 仅做快速收录与状态选择（稍后看/待内化）。
- 不承担管理与深度编辑功能。

## 9. V1 边界

V1 聚焦：
1. 收录箱处理效率
2. AI 自动内化与自动结构整理
3. 图谱成果浏览
4. 证据化 AI 问答与回写沉淀

V1 不做：
- 用户手工搭建复杂层级体系
- 多层主题扩展（如子子主题）
- 偏离知识场景的通用聊天能力
